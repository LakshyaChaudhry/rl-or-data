# Workshop files

This directory is separate from the experiment code, the pre-registration, and the result logs.

- `preserved-arxiv-v1/` is a copy of arXiv:2610.25812v1. Do not edit it.
- `original-recompile/` is a local `pdflatex` build of that source. It is a compile check.
- `aaai27-provisional/` is a venue-neutral condensation in the official AAAI 2027 author kit. It is not a submission, and it does not name a workshop.
- `reviews/` holds four independent reviewer reports and the synthesis.

The primary PDF is `aaai27-provisional/latex/main.pdf`.
`main-anonymous.pdf` is a conditional compile. Its first page says public sharing is prohibited. Do not send it out.

No training run, submission, organizer email, or registration was performed for these files.
